# 新手快速上手指南（完全沒用過電腦命令也能跟著做）

這份指南是給**完全的新手**看的 —— 就算你沒聽過「終端機」、沒裝過 Python、
沒用過 AI，只要照著一步一步做；安裝完成後，大約 **5 分鐘**就能用圖形工作台試看
示範分析，再帶入自己的交易、
看出自己到底是在投資還是在賭博、甚至檢查自己是不是遇到投資詐騙。

> 看不懂某個詞沒關係，照著打就對了。每一步都會告訴你「應該會看到什麼」，
> 對得上就代表你做對了。

## Windows 10/11 x64：可攜版 3 步驟

不想先安裝 Python？Windows 10/11 x64 可以直接使用可攜版：

1. 從 [v0.3.0 發行頁](https://github.com/mars-tw/anti-gambling-trader-tw/releases/tag/v0.3.0)
   下載 [AntiGamblingTrader-windows-x64.zip](https://github.com/mars-tw/anti-gambling-trader-tw/releases/download/v0.3.0/AntiGamblingTrader-windows-x64.zip)。
2. 解壓縮**整個資料夾**，不要只把裡面的 exe 單獨拖出來。
3. 雙擊 `AntiGamblingTrader.exe`，再選擇本機瀏覽器版或獨立應用程式視窗。

這個可攜版適用 Windows 10/11 x64。桌面視窗需要電腦已安裝 Microsoft Edge WebView2 Runtime；
若未安裝或桌面視窗無法開啟，請選本機瀏覽器版。WebView2 Runtime 不會隨 ZIP 一起打包。

Windows 可攜版使用者完成上面 3 步驟後，可以跳過下面的 Python、終端機與原始碼安裝步驟。

## 原始碼／Mac／Linux 路徑（可選）

以下內容只給使用原始碼、Mac 或 Linux 的讀者；Windows 可攜版使用者可以略過，直接閱讀後面的使用說明。

### 安裝完成後，先選你要的畫面

最簡單的入口是：

```bash
anti-gambling-trader ui
```

小選擇器會讓你決定：

- **本機瀏覽器版**：不需額外套件；也可直接執行
  `anti-gambling-trader ui --mode browser`。
- **桌面視窗版**：需先執行 `pip install -e ".[desktop,excel]"`；Windows 還需要
  Microsoft Edge WebView2 Runtime。若開不起來，改用瀏覽器版即可。

Windows 原始碼使用者也可雙擊專案根目錄的 `start-ui.cmd`。它不會偷偷安裝套件。
畫面依序帶你「試樣本 → 匯入或手動記錄 → 看完整性、階段與圖表 → 視需要跑資金情境
→ 下載報告 → 紙上專案」。
樣本一定標示為示範，不是你的成績。

> 工作台只連本機 `127.0.0.1`。原始匯入檔不會被修改；分析可能使用本機暫存檔。正常完成
> 或正常結束會清理這些暫存，但非預期失敗或強制停止可能讓系統暫存檔留在本機。報告與
> CSV 只有在你主動下載後才會成為持久副本；下載「目前紀錄 CSV」後，重新啟動工作台可在
> 「載入先前逐筆紀錄」重新載入，繼續之前的紀錄。只關瀏覽器分頁不等於停止服務，請按
> 「結束本次使用」或回終端機按 `Ctrl+C`。
>
> GUI **不提供實盤**：沒有券商金鑰欄、沒有解鎖、沒有真單。紙上專案 ZIP 固定使用
> PaperBroker，只是待你填策略的鷹架。

### 看懂 0.3.0 的四組證據

匯入完成後，「分析結果」會先保留原本的完整性、核心階段與關鍵數字，接著顯示：

1. 依真實平倉時間排列的累積已實現淨損益與回撤金額；缺時間或同時點順序不明就不畫。
2. 每筆淨損益的直方圖、零線、最小／P05／Q1／中位數／Q3／P95／最大值與平均。
3. 核心實際使用的前段／後段單一 holdout；兩張卡使用相同尺度，但它不是行情回測。
4. 另行啟動的資金警戒線情境。起始資金預設空白，請填真實金額並確認幣別；「10」預設
   表示剩餘本金 10%，也可明確切換為剩餘固定金額 10，或虧損本金 10%。

資金情境用過去每筆固定幣別淨損益有放回重抽，不複利、不改部位、不執行上傳的 Python，
也不是未來獲利或券商強平預測。跌破門檻後停止並保留實際穿越金額；0/N 只代表本次有限
路徑未出現，不代表風險為零。修改任何情境欄位後，舊結果會立刻停止顯示與匯出。

## 第一步：安裝 Python（可選；原始碼／Mac／Linux 使用者）

> Windows 可攜版使用者不需要安裝 Python，也不需要完成本節與後續原始碼安裝步驟。

這個工具是用一種叫 **Python** 的程式語言寫的，所以要先把 Python 裝到你的電腦上。
**只需要裝一次**，以後就不用再裝了。

### 🪟 如果你用 Windows

1. 打開你的網頁瀏覽器（Chrome、Edge 都可以）。
2. 在網址列輸入 **python.org/downloads** 後按 Enter。
3. 你會看到一個黃色的大按鈕，寫著 **「Download Python 3.x.x」**（x 是數字），點它。
4. 下載完成後，打開那個檔案（通常在「下載」資料夾，檔名像 `python-3.x.x.exe`）。
5. **⚠️ 非常重要**：安裝畫面最下方有一個小框框
   **「Add Python to PATH」**（把 Python 加入 PATH），**一定要打勾！**
   （沒勾的話後面會找不到 Python。）
6. 然後點 **「Install Now」**，等它跑完，看到「Setup was successful」就完成了。

### 🍎 如果你用 Mac

1. 打開瀏覽器（Safari、Chrome 都可以）。
2. 在網址列輸入 **python.org/downloads** 後按 Enter。
3. 點黃色大按鈕 **「Download Python 3.x.x」**。
4. 下載完成後，打開那個檔案（檔名像 `python-3.x.x.pkg`）。
5. 一直點「繼續」→「同意」→「安裝」，輸入你開機的密碼，等它跑完即可。

## 第二步：打開「終端機」（你輸入指令的地方）

「終端機」是一個可以打字下指令給電腦的黑色（或白色）視窗。聽起來很難，
其實你只要會**複製、貼上、按 Enter** 就夠了。

### 🪟 Windows 打開終端機

1. 按鍵盤左下角的 **田字鍵（Windows 鍵）**，或點螢幕左下角的開始圖示。
2. 直接打字輸入 **PowerShell**。
3. 看到 **「Windows PowerShell」** 出現，點它打開。
4. 會跳出一個藍色或黑色的視窗，游標在閃 —— 這就是終端機，準備好了。

### 🍎 Mac 打開終端機

1. 按鍵盤的 **Command（⌘）+ 空白鍵**，會跳出搜尋框（Spotlight）。
2. 輸入 **Terminal**（終端機）。
3. 按 Enter，會打開一個白色或黑色的視窗 —— 這就是終端機。

### ✅ 確認 Python 裝好了

在終端機視窗裡，**複製貼上**下面這行，然後按 Enter：

```
python --version
```

> Mac 使用者如果出現錯誤，改打 `python3 --version` 試試。

如果看到類似 **`Python 3.10.x`**（或更大的數字）就代表裝對了！
如果出現「找不到」之類的錯誤，回到第一步重裝，**記得把「Add Python to PATH」打勾**。

5. 記住解壓縮後的資料夾位置（例如桌面）。

## 第四步：進入工具的資料夾並安裝

### 1. 進入資料夾

我們要讓終端機「走進」剛下載的資料夾。在終端機打 `cd `（**cd 後面有一個空格**），
然後把資料夾**直接拖進終端機視窗**（拖曳那個資料夾到黑視窗上放開），
它會自動填上路徑，最後按 Enter。

例如看起來會像這樣（你的路徑會不一樣）：

```
cd C:\Users\你的名字\Desktop\anti-gambling-trader-tw
```

> 小技巧：拖曳資料夾到終端機是最不會打錯字的方法。

### 2. 安裝工具

進到資料夾後，貼上這行按 Enter（**Mac 若 `python` 沒反應就改 `python3`**）：

```
python -m pip install -e .
```

等它跑個幾十秒，看到一堆文字跑完、最後沒有紅色錯誤，就裝好了。

## 第五步：開始使用！（最重要的部分）

### 🧭 不知道先做哪一個？

先開圖形工作台（推薦新手）：

```
anti-gambling-trader ui
```

想沿用命令列分流也可以：

安裝後先執行：

```
python -m core.cli start
```

它會依你手上是完整紀錄、單筆交易、交易截圖或 LINE 對話，顯示一條最短路徑。
不用一次學會所有指令。

### 🎬 先看個示範（不用準備任何資料）

直接貼上這行按 Enter：

```
python -m core.cli demo
```

你會看到一份完整的中文分析報告 —— 這是一個「賭博型」交易的範例，
工具會告訴你它為什麼判定這是賭博。**這就是工具的效果**。

想看「有賺錢、有方法」的對照範例，打：

```
python -m core.cli demo --edge
```

### 📝 分析你自己的交易

#### 最簡單：不用 Excel，五個短問題記一筆

```
python -m core.cli record
```

依序填「代號、方向、已實現淨損益、平倉日期／時間、當時的進場理由」。淨損益
必須同時寫出**帳戶結算幣別**，且是**已扣手續費／稅／滑價**的數字
（例如 `-1250 TWD`；只填 `-1250` 會被拒絕）。若不知道，
工具才會改問進場價、出場價與數量。每次平倉後再執行一次，資料會安全附加到
`my_trades.csv`；不會覆蓋舊紀錄。

累積紀錄後，先用精簡分流看目前適合哪一步：

```
python -m core.cli fit-check my_trades.csv
```

輸出只會分成「停手檢查方法、紙上模擬、極小額驗證」。即使統計與樣本外都通過，
也不會說你適合重押或全職交易。

| 畫面結論 | 代表什麼 |
|---|---|
| 停止投入真錢 | 期望值不為正，或整體證據仍要求勸退 |
| 只適合紙上模擬 | 少於 30 筆、樣本外未延續，或風險／幣別／時間基準不可靠 |
| 可考慮極小額驗證 | 樣本內外皆有顯著正期望，規則事前凍結，且風險基準完整；仍不是重押許可 |

完整條件見[完整功能與判讀指南](user-guide.md#2-是否適合交易到底怎麼判斷)。

#### 想用 Excel：產生範本

#### 步驟 1：產生一個空白表格範本

```
python -m core.cli init-template
```

這會在資料夾裡產生一個叫 **`trades_template.csv`** 的檔案。

#### 步驟 2：填入你的交易

用 **Excel** 或**記事本**打開 `trades_template.csv`，你會看到欄位：

| 代號 | 方向 | 進場時間 | 出場時間 | 進場價 | 出場價 | 數量 | 手續費 | 損益 | 損益幣別 | 策略 |
|------|------|----------|----------|--------|--------|------|--------|------|----------|------|

把裡面的範例換成你自己的交易，一行 = 一筆「已經買賣完成」的交易。例如：

| 2330 | 買 | 2025-01-03 | 2025-02-10 | 1000 | 1080 | 1000 | （留空） | （留空） | TWD | 季線突破 |

如果券商已經顯示「已實現淨損益」，最簡單只填 **代號、方向、出場時間、淨損益、損益幣別、策略**；
進出場價與數量可留空。這種簡易紀錄能判讀金額期望值，但因缺少部位基準，
報酬率與回撤百分比會誠實標成無法計算。

> **簡易紀錄的上限：** 只有 direct P&L 而沒有進場價與數量時，`fit-check` 即使看到
> 金額優勢與樣本外延續，仍會停在「缺可靠風險基準，只適合紙上模擬」。若未來要考慮
> 極小額驗證，必須補齊進場價、數量、正確契約乘數、帳戶結算幣別與完整平倉時間。

- **代號**：股票代號（台股像 2330）或幣別（像 BTCUSDT）。
- **方向**：用價差推算損益時必須填「買/做多」或「賣/做空」，不能按空白默認做多；
  若已填券商 direct net pnl 但真的不知道方向，可留白，工具不會拿它反推方向偏好。
- **手續費**：只有用進出場價與數量推算損益時，留空才會估算。直接填 pnl 時，
  pnl 必須已扣全部成本，工具不會再扣一次。
- **損益欄名**：建議用 `pnl`、`損益`、`net_pnl` 或「淨損益」。只有寫
  `盈虧`、`已實現損益`、`realized_pnl` 時，工具無法知道是否已扣成本，會請你
  改成明示淨額的欄名，或用 `--field pnl=你的欄名` 親自確認。
- **損益幣別**：direct pnl 必填 TWD、USD、JPY、USDT 等帳戶結算幣別；
  不同幣別不會直接相加。只有由價量推算時才可採商品原生報價幣別。
- **策略**：填你「為什麼買」的理由（例如「聽老師明牌」「自己看技術線」）。
  **強烈建議認真填** —— 這樣工具才能告訴你「哪一招在送錢」。
- 開頭有 `#` 的那幾行是說明，可以留著（分析時會自動跳過）。

填好後**存檔**。用 Excel 的話，存檔格式建議選「**CSV UTF-8**」；
選一般「CSV」也可以（工具會自動嘗試 Big5 編碼），但 UTF-8 最保險。

#### 步驟 3：分析它

```
python -m core.cli analyze trades_template.csv
```

（如果你把檔名改了，就把上面的 `trades_template.csv` 換成你的檔名。
檔名有空格的話，用拖曳的方式把檔案拖進終端機最保險。）

按 Enter，幾秒後就會出現你的**專屬分析報告**：你是優勢還是賭博、
哪一招在送錢、勝率要到多少才會轉正、有沒有詐騙嫌疑……全部都有。

為避免誤蓋原始紀錄，`--json`、`--html`、`--strategy`、`--card` 的路徑若與輸入檔
或彼此指向同一檔案，指令會在寫入前拒絕；既有報告檔也預設不覆蓋。請換一個新檔名。

> 💡 **兩個不用緊張的現象**:
> 1. 範本只有 2 筆示範交易,直接分析會得到「**樣本不足**」——這是正常的、
>    也是誠實的:2 筆資料本來就不能下任何結論。填入你自己的交易
>    (最好 30 筆以上)才會看到完整裁決。
> 2. 報告印完後,指令的「結束代碼」可能是 2 而不是 0——那**不是錯誤**,
>    是刻意設計:裁決為「勸退」時用非零代碼方便自動化腳本判斷。
>    報告有正常印出來就沒問題。

### 🛡️ 檢查自己是不是遇到詐騙

如果你被拉進什麼飆股群、有人保證獲利、叫你升級 VIP 或匯款到某平台，
打這行做個自我檢測：

```
python -m core.cli scam-check
```

它會問你幾個是非題（打 `y` 是 / `n` 否，按 Enter），最後告訴你詐騙風險高不高、
該怎麼自保。

如果你已經從 LINE 匯出對話紀錄，可直接掃描整份文字：

```
python -m core.cli scan-text --file LINE對話.txt
```

工具會保留發言者、時間、原句與命中理由，並把同一人在短時間拆開傳送的話術合併判讀。
結果只有「極高／高／中／低」序數等級，不會捏造「詐騙機率 87%」；低風險也不代表安全。
具體規則是同一發言者、同一天、10 分鐘內，最多組合 6 則與 600 字；不會跨人或跨日拼接。
否定與反詐警語只作用在實際命中的子句，不會洗掉後續真正的匯款指令。

### 📷 從交易截圖整理點位

安裝圖片 OCR 選配後（系統另需 Tesseract 與繁中字庫）：

```
python -m pip install -e ".[screenshot]"
python -m core.cli scan-screenshot 券商截圖.png
```

它會列出標的、方向、進出場價、數量、時間、已實現損益、停損／停利的候選值，
每一欄都附原文證據。低信心、數字衝突、損益正負號不明時一定留給你確認，
不會自動寫入交易紀錄。也會標出突破、均線、RSI、MACD 等文字線索，但這些只代表
畫面出現相關字樣，不能認證你真的依此交易，更不能證明策略有優勢。
逐欄對照原圖後，再把確認過的值交給 `record`；不要直接把 OCR JSON 當成交紀錄。

若電腦尚未裝 OCR，可先用手機或系統的「複製圖片文字」，再執行：

```
python -m core.cli scan-screenshot --text "貼上的 OCR 文字"
```

圖片路徑、`--text-file`、`--text` 三種來源一次只能選一個。逐欄檢查正負號、小數點、
已實現／未實現、幣別，以及股／張／口／幣等單位；完整清單見
[完整功能與判讀指南：交易截圖與點位覆核](user-guide.md#7-交易截圖與點位覆核)。

### 🚧 為什麼有些指標會顯示無法計算？

這通常不是程式壞掉，而是工具拒絕猜測：

- 缺少或全部相同的平倉時間，不會用列順序冒充樣本外時序；
- TWD、USD、USDT 等不同或不明幣別不直接相加；
- 期貨／選擇權乘數未知時，不用 `1` 猜名目本金；
- direct P&L 沒有可信部位基準時，只算金額，不印虛假的報酬率與回撤百分比；
- OCR 正負號、單位或候選值衝突時，一律留給人工確認。
- 任何資料列被拒絕，或完整時間戳交易出現未釐清的精確重複時，只把保留列當描述樣本，
  不給正優勢裁決，也不做樣本外切分。

可依報告警語補資料；不要為了得到綠色結果自行填入猜測值。完整矩陣見
[Fail-closed 說明](user-guide.md#4-資料不完整時工具如何-fail-closed)。

## 常見問題

**Q：打 `python` 沒反應 / 說找不到？**
A：Mac 改打 `python3`。Windows 的話，多半是裝 Python 時忘了勾
「Add Python to PATH」，重裝一次並勾起來。

**Q：中文變成亂碼？**
A：Windows（PowerShell）先執行 `$env:PYTHONUTF8=1`，再照常跑指令；
Mac / Linux 則在指令最前面加 `PYTHONUTF8=1`，例如
`PYTHONUTF8=1 python -m core.cli demo`。

**Q：它會告訴我「買什麼股票會漲」嗎？**
A：**不會，而且這正是重點。** 任何宣稱能報明牌、保證獲利的，
都該高度懷疑是詐騙。這個工具只做一件事：用數學誠實告訴你過去的成績，
幫你別再被「穩賺」的話術騙。

**Q：我的交易資料會被傳到網路上嗎？**
A：直接執行本機 CLI 時不會由本專案上傳；但把檔案／輸出交給雲端 AI、開啟會載入
外部 CDN 的圖表，或啟用券商/API 路徑，都可能產生對外連線。分享前先遮蔽個資與帳號。

**Q：它可以做自動化交易嗎？**
A：可以產生自動化交易程式腳架，紙上模擬可直接執行；真實自動交易仍需你自行
接妥券商 API、即時行情 runner，並在自訂 live runner 中沿用四層安全檢查。
預設歷史 runner 不會送真單；只有你自行填入金鑰並明確解鎖後，live adapter 才可能
送單。這些條件也不保證自動交易能獲利。
