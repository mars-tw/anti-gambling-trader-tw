# 反詐投資王

## 新手圖形工作台

安裝後先執行 `anti-gambling-trader ui`，即可選擇**本機瀏覽器版**或
**桌面視窗版**。兩者使用同一套只監聽 `127.0.0.1` 的服務與相同畫面：先試明確
標示的樣本，再匯入／手動記錄、查看資料完整性與核心階段、下載報告，最後才視需要
下載固定 PaperBroker 的紙上專案鷹架。

```bash
pip install -e .                         # 瀏覽器版
anti-gambling-trader ui --mode browser

pip install -e ".[desktop,excel]"       # 桌面視窗 + Excel 選配
anti-gambling-trader ui --mode desktop
```

Windows 桌面視窗需要 Microsoft Edge WebView2 Runtime；缺少時改用瀏覽器版。
手動紀錄與分析可能使用本機暫存檔；原始匯入檔不會被修改。正常完成或正常結束會清理這些
暫存，但非預期失敗或強制停止可能讓系統暫存檔留在本機。要保留的資料請主動下載；下載的
CSV／報告是明確建立的持久副本。下載目前紀錄 CSV 後，重新啟動工作台可在「載入先前逐筆紀錄」
重新載入，繼續之前的紀錄。只關瀏覽器分頁不會停止服務，請按「結束本次使用」或在終端機按
`Ctrl+C`。GUI 不收券商金鑰、不連券商、不送真單；本文件站只是說明頁，並不是雲端分析 App。

**這是一個免費、開源、在你自己電腦上執行的工具**,做三件事:

1. **查證投資詐騙**:掃描 LINE / Telegram 投資群的話術、檢驗「老師」的勝率與績效宣稱、鑑識可疑對帳單。
2. **交易統計分析**:把你的交易紀錄(CSV / JSON / Excel)丟進去,用期望值與統計檢定判斷獲利是「可重複的優勢」還是「運氣」。
3. **建立自動化交易程式**:產生可回測策略與自包含交易程式專案,預設使用
   `PaperBroker`,並提供 13 種真實券商／交易所範本供使用者自行接線與驗證。

> 🤖 紙上模擬可直接執行；自行實作真實自動交易時，仍需接妥券商 API、即時行情
> runner，並沿用四層安全檢查。預設生成的歷史 runner 不會送出真單；只有使用者
> 自行填入金鑰、完成 live runner 並明確解鎖後，live adapter 才可能送單。

> **🚨 疑似遇到投資詐騙?先做這三件事**
>
> **停止匯款**(包括任何「稅金/保證金/解凍費」)、**保留證據**(對話、帳號、匯款紀錄)、
> **撥打 165 反詐騙專線**或上 [165 全民防騙網](https://165.npa.gov.tw) 查證與報案。
> 匯款後越快報案,銀行端攔阻的機會越大。

## 安裝與使用

免費開源(MIT 授權)。直接執行本機 CLI 時，交易資料由本機處理且程式不會上傳；
若把檔案或輸出交給 Claude Code／其他雲端 AI，內容可能依供應商政策傳送與保存，
請先遮蔽姓名、帳號與 LINE ID。參考
[Claude Code 官方資料使用說明](https://code.claude.com/docs/en/data-usage)。生成圖表可能載入
外部 CDN；自行啟用券商/API 路徑也會明確連線外部服務。
完全沒用過終端機?看[新手快速上手指南](quickstart.md)，安裝後約 5 分鐘可跑出第一份示範報告。

```bash
git clone https://github.com/mars-tw/anti-gambling-trader-tw.git
cd anti-gambling-trader-tw
pip install -e .           # 安裝
anti-gambling-trader start # 依手上的素材選最短路徑
anti-gambling-trader demo  # 沒資料時先看明確標示的內建範例
```
