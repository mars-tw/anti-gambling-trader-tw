## 已修正的問題

| 編號 | 影響與原始重現 | 修正與驗證 |
|---|---|---|
| 01 | CSV／Excel 的重複 `pnl` 欄、JSON 重複鍵，以及 `pnl`／`P N L` 正規化碰撞會覆寫前值。合成 60 筆 `-1000,+100` 曾錯報 `+6000` 並產生優勢判定。 | 在轉成字典前拒絕同名及正規化碰撞；欄位 override 不能繞過。涵蓋 CSV、TSV、Excel、JSON，並確保 workbook 在錯誤路徑關閉。 |
| 02 | `TWD 100 − USD 50` 曾被算成 `50 TWD`；價格單位也可能被移除後錯標成商品原生幣別。手動輸入存在同樣入口。 | 在運算、成本估計及存檔前核對原始單位。不做匯率換算；矛盾報價先拒絕。已結算 net 損益與外幣選用成本分開處理，無可靠分母時停用 ROI。 |
| 03 | 新手紀錄使用六位有效數字保存數值，`70200.01 → 70200.02` 會變成 `70200 → 70200`。 | 保存可往返的浮點文字；價格、小數數量、費用及直接損益均加入回歸案例。 |
| 04 | 舊 CSV 沒有結尾換行時，新增列會和上一列黏在一起，回報 2 筆卻只讀回 1 筆；合成虧損曾因此消失。 | 先確認編碼可寫，再補符合舊檔慣例的分隔換行；UTF-8／Big5 及編碼失敗不改檔均驗證。 |
| 05 | 解析破產公式在 `(1000,2000,0.3)` 等合法參數溢位；接近公平勝率時的固定近似門檻也不可靠。 | 改用 log／expm1 的穩定等價式。獨立 122 個 Decimal 對照最大絕對誤差約 `3.33e-16`，並拒絕 6 類無效機率輸入。未更動 Monte Carlo 抽樣或門檻語義。 |
| 06 | `USDT`／`USDC` 前綴會先被短碼 `USD` 誤吃；金額緊鄰幣別時也可能辨識失敗。 | 統一最長字碼及數字邊界辨識；帶空格／緊鄰形式可用，多重或跨幣別標註拒絕。 |
| 07 | Backtrader 骨架的 `self.order` 在成交後仍非空，後續直接 return，跳過停損／停利。 | 依目前訂單 ref 清除終態，保留 pending／partial，舊通知不能清除新訂單。真正 Backtrader 1.9.78.123 的離線五根價格測試由「買入後仍持倉」改為「買入 100、停損賣出 80、持倉 0」。 |
| 08 | Shioaji 帳戶合法查詢只有 `market`，worker 卻無條件要求時間／筆數欄位，導致帳戶查詢在登入前被拒絕。 | 依資料種類驗證欄位；使用實際父端 schema 到合成 worker 的最小帳戶查詢、帳戶選擇與登出流程驗證。 |
| 09 | Shioaji 歷史分鐘結束標籤被當成開始時間，造成五分 K 的開收價／成交量分組錯誤，收線也多等一分鐘。 | 僅歷史 K 線先正規化為 bar-open，再做範圍、缺分鐘及聚合檢查。09:05 五分棒合成對照為 `O106/C110/V40`，第一根及已收／未收狀態均驗證。 |
| 10 | Binance 的交易對 metadata 占用一筆成交額度，合法 5,000 筆查詢因此超限。 | metadata 計頁數但不計成交筆數；真正 `SyncContext` 下 4,999／5,000 筆均完整成功，頁數、時間與大小限制保留。 |
| 11 | API 工作尚未完成時離頁，或在開始請求 ACK 前改參數，可能停止輪詢卻留下 running 狀態，永久鎖住按鈕。 | 分開自動刷新與自有工作的取消／終態處理；晚 ACK 不接管新參數，取消後可重新查詢。 |
| 12 | 分析回應前撤回確認或改查詢，舊成功回應仍會恢復分析與匯出。 | 回應綁定資料集、查詢及確認條件的世代；過期成功／失敗回應均不套用，重複點擊不重送，原始資料可保留重新確認。 |
| 13 | 選過 Shioaji 帳戶後改查 K 線或切到 Binance，仍夾帶不適用的 `account_ref`，導致合法查詢被拒絕。 | 僅 Shioaji 成交／帳戶查詢傳送該欄；切換來源或不適用種類時清除殘留選擇。 |

第 09 項的時間語義依據[固定 SDK 1.7.7 的官方市場資料文件](https://raw.githubusercontent.com/Sinotrade/Shioaji/v1.7.7/plugins/shioaji/skills/shioaji/references/MARKET_DATA.md)；第 07 項另核對了[Backtrader 訂單通知介面](https://www.backtrader.com/docu/strategy/)。均另外執行獨立重現，未僅憑文件判斷修復成功。

## 驗證與範圍

- 三條獨立稽核線分別檢查匯入／統計、API／憑證／程序、GUI／配置；修正由另外的執行者完成，再交叉複驗。
- 匯入／幣別另有 13 個回歸案例、4 個有效對照及正規化欄位 override 拒絕檢查；API 三類修正另有 20 個主要合約斷言。
- 實際瀏覽器使用可控延遲與合成資料，驗證取消後解鎖、晚 ACK、撤回確認、重新分析，以及帳戶／K 線切換。60 筆合成成交合併成 30 個週期，結果為 230 USDT、中位數 9 USDT；這不是個人或實盤績效。
- 全新零相依 wheel，以及中文／空白搬移路徑的 Windows 可攜版，三個啟動實例各通過 31 項 HTTP／產物檢查。正式可攜版另由實際瀏覽器成功讀回 Binance 公開 K 線 24 筆，未使用私有憑證。
- 桌面版實際以 Edge Chromium 啟動，視窗 accessibility tree 與同一實例的 HTTP 功能可讀回；本輪原生輸入回報存取拒絕，螢幕擷取為黑畫面，因此不計為完成桌面視窗目視操作驗收。
- 打包、全新安裝、搬移路徑、啟動／關閉及發布附件的最終驗收記錄保存在正式交付目錄的 `verification.json`，以該份實際回讀為準。

本次未使用真實券商金鑰登入或讀取帳戶，未做全機惡意程式掃描或宣稱第三方二進位完全無漏洞。通過測試代表所列範圍與案例符合預期，不代表沒有其他 BUG、策略有未來優勢或可以解鎖實盤。
